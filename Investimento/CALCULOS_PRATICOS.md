## PARTE 9: ERROS NUMÉRICOS

### Erro #1: Achar que Poupança é Suficiente

```
Poupança: 2% a.a. (real: NEGATIVO após inflação)

Invest inicial: R$ 100.000
Aporte mensal: R$ 500
Período: 30 anos

Resultado: R$ 309.000

INSUFICIENTE para R$ 60k/ano (necessário: R$ 1.500.000)
```

### Erro #2: Market Timing (entrar/sair)

```
Carteira deve valer: R$ 1.889.000 (30 anos)

Mas você tenta:
- 2008: Sai na crise (perde recuperação 5 anos)
- 2010: Volta entusiasmado (compra caro)
- 2020: Sai de novo com medo
- 2021: Volta quando já subiu 30%

Resultado real: R$ 1.244.000 ❌
Perda pelo timing: -R$ 645.000 (-34%)
```

### Erro #3: Começar Muito Tarde

```
Pessoa A: Começa aos 25 com R$ 500/mês
Resultado aos 65: R$ 4.117.000

Pessoa B: Começa aos 45 com R$ 2.000/mês (4x mais)
Resultado aos 65: R$ 1.260.000

Pessoa A ganhou: 3.26x mais
Conclusão: 20 anos ganhando "pouco" > 10 anos ganhando "muito"
```

## 📚 FÓRMULAS ÚTEIS

### Fórmula 1: Meta de Aposentadoria
```
Meta = Despesa Anual ÷ 0.04
ou
Meta = Despesa Anual × 25
```

### Fórmula 2: Valor Futuro
```
VF = VP × (1 + i)^n + PMT × [((1+i)^n - 1) ÷ i]

Onde:
VP = Valor Presente
i = Taxa de retorno
n = Número de períodos
PMT = Aporte periódico
```

### Fórmula 3: Carteira Otimizada
```
Ações (%) = 100 - Sua Idade
Renda Fixa (%) = Sua Idade
```

### Fórmula 4: Impacto de Fee
```
Retorno efetivo = Retorno bruto - Fee
Exemplo: 8% - 0.5% = 7.5% efetivo
```
