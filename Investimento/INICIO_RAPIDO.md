## PASSO 1: Faça Seu Cálculo Pessoal (3 min)

**Pergunta 1:** Quanto você gasta por mês?
```
Minha resposta: R$ ________
```

**Pergunta 2:** Quanto isso é por ano?
```
Minha resposta: R$ ________
(Multiplique por 12)
```

**Pergunta 3:** Qual é sua meta de aposentadoria?
```
Fórmula: Despesa Anual ÷ 0.04 = Meta

Cálculo: R$ ________ ÷ 0.04 = R$ ________
```

**Exemplo Real:**
```
Despesa mensal: R$ 5.000
Despesa anual: R$ 60.000
Meta de Aposentadoria: R$ 60.000 ÷ 0.04 = R$ 1.500.000
```

---

## PASSO 2: Compare com Realidade (3 min)

**Quanto você vai receber do INSS?**

Faça aqui: www.gov.br/meu-inss (sua conta)
```
Minha estimativa: R$ ________
```

**Quanto falta?**
```
Meta de Aposentadoria - INSS = Patrimônio Necessário

R$ ________ - R$ ________ = R$ ________
```

**Exemplo:**
```
Meta: R$ 1.500.000
INSS estimado: R$ 30.000/ano
Patrimônio necessário: R$ 1.500.000 - (30.000÷0,04)
                      = R$ 1.500.000 - R$ 750.000 = R$ 750.000
```

## ⚠️ ERROS QUE NÃO COMETER

1. **NÃO comece sem calcular sua meta**
   → Sem meta, você investir sem rumo

2. **NÃO invista tudo em um ativo**
   → Sem diversificação, risco é alto demais

3. **NÃO saia quando crise vem**
   → 2008: Quem vendeu perdeu, quem manteve ganhou

4. **NÃO pague fees altos (>0.5% a.a.)**
   → Fees altos = R$ 100k perdidos em 30 anos

5. **NÃO tente fazer day trading**
   → 99% das pessoas perdem dinheiro nisso

## 📞 PRÓXIMAS DÚVIDAS?

**Dúvida comum:** "E se eu começar com R$ 100?"
```
R$ 100/mês durante 30 anos a 8% a.a. = R$ 151.000

Pequeno? Sim.
Mas se fizer R$ 500/mês = R$ 755.000
Se fizer R$ 1.000/mês = R$ 1.510.000 ✓ Suficiente!

Lição: Não importa quanto começa.
Importa: COMEÇAR E MANTER
```

**Dúvida comum:** "E se o mercado cair?"
```
2008: Caiu 40%
Quem manteve investindo:
  - Comprou ações mais baratas
  - Em 2013: Recuperação + 30% de lucro extra

Lição: Crise = Oportunidade, não desastre
```

**Dúvida comum:** "Preciso de muito dinheiro para começar?"
```
Não. Com R$ 50-100 você consegue abrir conta.
Depois? Invista o que puder:
  - R$ 50/mês = Lento mas funciona
  - R$ 500/mês = Muito bom
  - R$ 1.000/mês = Excelente

Lição: Qualquer quantia funciona
Importa é CONSISTÊNCIA
```
